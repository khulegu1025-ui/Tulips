BLUE TULIPS WEBSITE

How to open it:
1. Extract this ZIP.
2. Open index.html in your browser.
3. Click Open your flowers. Sound starts only if you turn it on.

Files:
index.html - the page, text, and flower color gradients
styles.css - layout, colors, and animations
garden.js - flower drawings, blooming, replay, sparkles, and soft sound
favicon.svg - the browser tab icon

No installation, libraries, build tools, or internet connection required.
You can edit the files using any text editor. Keep all four files together.
To host it, upload all four files to any static website host.
